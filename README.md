# SMART DRAIN & HEATWAVE RESPONSE SYSTEM

## Team ACE

스마트 배수 시스템과 폭염 대응 시스템을 주제로 한 발표자료 제작 프로젝트입니다.

## 발표자료 제작 방향

- 최종 결과물은 PDF 형식으로 제작합니다.
- 전체 슬라이드는 흰색 배경을 기본으로 합니다.
- 많은 색상을 사용하지 않고, 최소한의 색상만 활용합니다.
- 핵심 내용이 명확하게 전달되도록 간결하고 일관된 디자인을 유지합니다.
- 텍스트와 시각 자료의 가독성을 우선합니다.

발표 목적, 주요 내용, 슬라이드 구성, 시각 자료 및 세부 디자인은 추후 확정하여 추가합니다.
